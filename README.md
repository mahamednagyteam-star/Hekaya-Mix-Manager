# Hekaya Mix Manager

نسخة منظمة وقابلة للبناء من سكربت **ETISALAT Hekaya Automatic Mix Stacker V3**. التطبيق يعمل من خلال الطرفية ويحافظ على جلسات الحساب، نقاط الاستئناف، وإدارة الإيقاف المؤقت الموجودة في السكربت الأصلي.

> استخدم التطبيق فقط مع أرقام وحسابات تملكها أو لديك تفويض صريح لإدارتها، وراجع شروط خدمة مزود الاتصالات قبل الاستخدام.

## المتطلبات

- Python 3.9 أو أحدث.
- اتصال بالإنترنت أثناء تشغيل العمليات التي تتواصل مع خوادم الخدمة.
- Windows هو النظام الأنسب لاختصارات لوحة المفاتيح المدمجة. يمكن تشغيله على Linux/macOS مع اختلاف دعم الاختصارات.

## التشغيل من المصدر

```bash
python -m venv .venv
# Windows
.venv\\Scripts\\activate
# Linux/macOS
source .venv/bin/activate
python -m pip install -r requirements.txt
python mix_v3.py
```

## بناء ملف تنفيذي

### Windows

شغّل:

```bat
build_windows.bat
```

سيتم إنشاء الملف:

```text
dist\\HekayaMixManager.exe
```

### Linux/macOS

```bash
./build_unix.sh
```

سيتم إنشاء الملف:

```text
dist/HekayaMixManager
```

> يجب بناء التطبيق على نفس نظام التشغيل المستهدف؛ PyInstaller لا ينتج ملف Windows من Linux أو العكس.

## الاستئناف ونقاط الأمان

ينشئ التطبيق ملفات تقدم باسم `mix_v3_progress*.json` بجانب البرنامج. هذه الملفات مستثناة من Git لأنها قد تحتوي على بيانات تشغيل حساسة. لا ترفعها إلى مستودع عام.

## ملاحظات أمنية

- لا تضع كلمات المرور أو رموز الدخول داخل الكود أو المستودع.
- لا تشارك ملفات `mix_v3_progress*.json`.
- عند استخدام مستودع عام، راجع إعداد الخصوصية قبل نشر الكود.
